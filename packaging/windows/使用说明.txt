Leica M9 For Nikon — Windows NVIDIA 免安装候选版

状态：本地候选包。第二台电脑离线验收和模型/调色资源的再分发许可尚待确认，暂不对外分发。

1. 完整解压 ZIP 到可写的短目录，例如 D:\M9。不要在压缩包内直接启动。
2. 电脑需为 Windows 10/11 x64，具备兼容的 NVIDIA 显卡及已安装的 NVIDIA 驱动。
   本包自带 Python、模型、CUDA 用户态库；无需另装 Python 或 CUDA Toolkit。
   CUDA 12.8 的驱动兼容性需要实际核对，不保证所有 NVIDIA 显卡可用。
3. 双击“环境诊断.cmd”。通过只表示环境、文件完整性和合成网络自检通过。
4. 双击“启动程序.cmd”，添加 NEF，选择输出目录，点击“直接 NEF 处理”。
   原生 NEF 不需要联网；设备固定为 cuda。显卡/显存错误会显示失败，不会改用 CPU。
5. original 为默认全尺寸策略；phone 为既有对照策略。均运行原有 tele 管线。
6. “自动转 DNG 处理”需另行安装 Adobe DNG Converter。本包不含该转换器。
   转换失败不会自动改为原生 NEF；可通过 M9_DNG_CONVERTER 指定已安装的转换器。
7. 停止或关闭时允许当前照片完成，再停止后续任务。失败项可重新入队。
   队列仅在本次会话保存；原片和重名成片不会被覆盖。
8. 日志位于 %LOCALAPPDATA%\LeicaM9ForNikon\logs。
   日志可能包含照片路径及错误信息；反馈前检查个人信息，按需自行清理旧日志。
9. 更新时关闭旧程序，将新版本解压到新目录。没有自动更新或后台上传。
   删除程序目录即可移除程序；照片、输出目录和上述日志需自行保留或删除。

已验证设备及资源占用见随附验收报告。最低驱动、最低内存/显存尚未通过跨设备测定。
本包较大：解压前请为 ZIP、解压后的程序及处理照片留足磁盘空间。
未签名候选包可能触发系统信誉提示；先核对外部 SHA256，不要关闭安全软件或忽略检测。

目前真实相机证据主要为 Z6 III、Z7 II，不代表所有尼康或所有 NEF 压缩格式都已支持。
输出为含 Display P3 ICC 的 SDR JPEG，并非 RAW 无损文件。
