# 基础 EXIF 与按轮模型会话

本次只增加拍摄信息保留和模型生命周期管理。完整 tele、额外 EV=0、D50、原网络权重/精度/选择门限、original/auto 默认值、JSON 默认关闭和输出发布规则保持现状。

## EXIF

`m9.exif.add_nef_exif()` 从原 NEF 的标准 TIFF/Exif IFD 读取白名单字段，native 与 DNG 使用同一来源。包含 Make/Model、LensMake/Model/Specification、拍摄时间及其时区/子秒、ExposureTime、FNumber、ISO、FocalLength/35mm 焦距和 ExposureBiasValue。拍摄曝光补偿是历史记录，不参与 M9 增益计算。

缺失、格式不合法、非有限、超出 EXIF 数值范围或过长的可选字段跳过，原因在返回的 `exif` 记录中保留。读取可选信息失败时仍构造基本方向/尺寸 EXIF；原有必需曝光、白平衡、矩阵等解码校验没有放宽。内存不足和中断仍向上传播。

只写允许的字段，不复制 GPS、序列号、MakerNote、Interoperability/sRGB 标记或原始缩略图。Orientation=1；IFD0 和 ExifIFD 尺寸取实际输出；ColorSpace=65535（Uncalibrated），由原有 Display P3 ICC 定义色彩。

序列化为有长度限制的 APP1，插入已编码 JPEG 的 SOI 后，保留其余段、ICC 和压缩图像数据，不解码或重新压缩。最终字节再交给既有临时文件、独占发布和回滚机制，报告的字节数及 SHA-256 以含 EXIF 的最终文件计算。JSON 开关不影响 EXIF。

## 模型会话

`NefSession` 固定解析后的设备，首次使用时严格加载 low/high/colorfix 并计算权重哈希。成功照片只复用模型和权重身份，每张仍独立解码、测光、计算 CCT 和选择风格网络。没有照片缓存、输出缓存、半精度、量化、编译或批量推理改动。

`process_nef()` 增加仅限关键字参数 `session=None`，原有位置参数兼容。单张调用自行创建并释放；GUI 默认处理器通过 `BatchJob` 的可选上下文工厂，在工作线程中为整轮创建一次会话。自定义处理器可以继续不使用工厂，批处理层不导入 NEF/GPU 模块。

失败会清理异常堆栈中已经退出的局部张量引用，清空后端模型、权重身份及 CUDA 缓存，允许下一张严格重载。正常完成、停止、异常、关闭窗口等待当前张完成后，整轮上下文退出清理，随后才发送 `finished` 并启用界面。下一轮会新建会话。清理错误应作为可见队列错误记录，不掩盖原始照片错误或伪改已成功照片的状态。

CUDA 缓存释放不等于销毁驱动上下文；结束后的 allocated/reserved、进程 RSS 和 nvidia-smi 是不同指标。

### 真实 GUI 生命周期

`gui_001/gui_validation.json` 记录真正默认 GUI 处理器和队列，native/original/auto、JSON 默认关闭。首轮三张全部成功，同一会话严格创建后端一次，high 3 次、colorfix 288 次；次轮新建会话，再加载三个网络。通过真实关闭确认“完成当前张后关闭”，完成 1628 后阻止第二张 0192 开始，后者保持 pending。每轮均先释放模型、CUDA allocated/reserved 归零，再发 `finished`，窗口最后销毁。

两轮共 high 4 次、colorfix 336 次，每个网络首次加载各 2 次（每轮一次）。四张新图去除 EXIF 后与冻结 tele JPEG/ICC 相同，EXIF、尺寸、原件哈希和无 JSON 旁文件通过。1631 次心跳、最大观测间隔 0.0744 秒，两轮含检查约 39.58 秒。

验收脚本额外的心跳计时回调在关闭时未取消，产生过一次已删除 Tcl 命令提示；脚本退出码为 0，清理/finished 顺序等断言全部通过。该提示属于独立测时脚本，已在 `gui_001/harness_note_001.json` 保留说明，没有通过修改产品或重跑掩盖。
